# Provide a File in a Thread with a Simple Assistant

1. Using the assistant from the previous exercise, ask the assistant to include `Ahab` and `Moby Dick` in the story

2. Evaluate how much detail and consistency the assistant provides in the story about these two characters

3. Continue the messages inside the same thread insisting in more content about these characters

4. Start a new thread and ask the assistant to generate the same story again from scratch

5. Upload a file with the contents of the book [Moby Dick](https://www.gutenberg.org/ebooks/2701) (public domain)

6. Ask again the assistant to include `Ahab` and `Moby Dick` in the new story
