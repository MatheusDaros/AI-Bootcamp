# Provide a File to NVidia Chat with RTX

1. Run the Chat with RTX application

   * Currently (as of March 2024) the application is only available on Windows 11 running on a compatible NVIDIA GPU

2. Using the "base" model, ask a story about `Ahab` and `Moby Dick`

3. Evaluate how the model behaves when not fed with the data to enrich the generation process

4. Include all the conversation in a single message, since the application does not keep context between messages

5. Pass a file with the contents of the book [Moby Dick](https://www.gutenberg.org/ebooks/2701) (public domain)

6. Ask again the assistant to generate a story about `Ahab` and `Moby Dick`

7. Make questions about specific things in the book to experiment with the RAG capabilities
