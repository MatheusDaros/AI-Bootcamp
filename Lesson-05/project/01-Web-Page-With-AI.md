# Building a Web Page with AI Generated Code

1. Let’s ask an AI to generate a HTML page for us using the following prompt:

   `Generate an HTML file with a simple chat interface and include a script to send the message somewhere when you click the "generate" button`

   * This simple prompt should be enough for generating the contents an html file to mimic the GUI of our application.

2. Let's see some examples from the best performing models currently available:

   * Meta's `codellama-70b-instruct`: [Response](./response-codellama-70b-instruct.md)

   * OpenAI's `gpt-4-1106-preview`: [Response](./response-gpt-4-1106-preview.md)

   * Anthropic's `claude-3-opus`: [Response](./response-claude-3-opus.md)

3. Pick the answer you found most useful and use it as a starting point for your HTML file

4. Open the `index.html` file that is located in this folder in you browser, and see how it looks like and how the page works
