# Generating Images with AI

## Using DALL·E-2 and DALL·E-3 with ChatGPT

1. Sign up to [ChatGPT](https://chat.openai.com/)

2. Start a new chat

3. Send a message asking explicitly for an image

   * Describe with your own words how you want the image to look like

4. View the results

## Using DALL·E-3 with Bing Image Creator

1. Sign up to [Bing Image Creator](https://www.bing.com/images/create)

2. Describe the image you want to create in the input bar

3. View the results
