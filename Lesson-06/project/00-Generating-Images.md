# Extending the Chef GPT App with Image Generation

1. Open the Chef GPT page we created in the last lesson in your IDE

2. Create a button to generate images for the dishes

3. The button should appear only after the user has requested a random dish

4. When the user clicks the button, the app should call the OpenAI API to generate an image for the dish

5. Display a loading spinner while the image is being generated

6. Display the generated image in the page when it's ready

7. Caption the image with the dish name

8. Display the recipe for that dish below the image in a text area
