# Lesson 16: AI Applications

In this final lesson we're going to wrap all the major concepts we've learned so far for generative AI, and we're going to put them into practice by creating a new application that integrates many AI functionalities.

By the end of this lesson you should be well prepared to start ideating and planning your final project, and you should be able to start prototyping your ideas by using the tools and replicating the techniques we used in all the lessons within this bootcamp.

## Prerequisites

* Complete all the exercises from the previous lessons
* Prepare a Text Generation API on your device
* Prepare an Image Generation API on your device
* Prepare a Computer Vision API on your device

## Review of Lesson 15

* Image generation techniques
* Generating videos
* Fine-tuning models
* LoRAs and VAEs
* Working with image datasets
* Extracting text information from images
* Computer Vision models
* Using transformers for image processing
* Using the Vision Process WebUI
* Processing image detection and classification tasks

## Implementing Many AI Tasks in Applications

* Computer Vision for processing input image
* Text generation for chat
* Contextual image generation
